# Кодекс Пульт

Личный Telegram-пульт для Codex в VS Code на macOS. Задания выполняются на компьютере пользователя в его беседах и проектах. Каждый пользователь создаёт своего Telegram-бота и входит в собственный аккаунт Codex. Общий сервер не нужен.

## Начать работу

Выполните [полную установку с нуля](SETUP.md): подготовка Mac → свой бот → локальные настройки → уведомления Codex → автозапуск → контрольная беседа.

Репозиторий содержит код, документацию, тесты и иконку. Токен, Telegram ID, настройки режима, очередь, история, вложения и логи создаются локально и исключены из Git. Клонирование не даёт доступ к аккаунту или проектам автора.

| Кто | Что читать и делать |

| Пользователь установленного пульта | [USER_GUIDE.md](USER_GUIDE.md): кнопки, ветки, очередь, вопросы и файлы |
| Разработчик | [DEVELOPER_GUIDE.md](DEVELOPER_GUIDE.md): устройство, проверка, обновление и ограничения |
| Агент, помогающий настроить или изменить проект | [AGENTS.md](AGENTS.md): порядок работы и обязательные технические правила |

В Telegram `/help` даёт короткую справку, `/guide` читает USER_GUIDE.md из установленной папки.

## Возможности

- Отдельная ветка Telegram для каждой беседы Codex.
- Запросы с компьютера и конечные ответы агента; запросы с телефона не дублируются.
- Общая очередь Codex для desktop и Telegram; пауза телефонной передачи и остановка выбранной беседы.
- 20 последних бесед, по 5 с кнопкой «⬇️ Вывести следующие 5 ⬇️». Предыдущие кнопки сохраняются.
- Создание общей беседы или беседы в недавнем проекте.
- Текст, изображения, документы, разовые разрешения и интерактивные вопросы, включая асинхронные.
- Получение готовых файлов по кнопке «Файлы».

Mac должен быть включён и не спать, а VS Code — владеть открытой беседой. Windows/Linux и другие редакторы для этого проекта не проверены. Приватный IPC расширения зависит от версии: проверенная среда и границы совместимости описаны в руководстве разработчика.

## Проверка

Из папки репозитория с активированным Python-окружением:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
```

На 10.10.2026 проходят 93 теста. Живые проверки смешанной очереди, перезапуска, вопросов и меню зафиксированы в плане разработки. Автотесты не заменяют контрольную беседу на новом компьютере.
