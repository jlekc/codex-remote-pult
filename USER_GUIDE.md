# Кодекс Пульт — инструкция пользователя

Бот @codex_remote_pult_bot позволяет получать ответы Codex и отправлять задания с телефона в беседы VS Code. Запросы выполняются на вашем Mac. Телефон служит пультом.

## Перед работой

Mac должен быть включён, подключён к интернету и не спать. VS Code и Codex должны работать. Откройте нужную беседу в Codex. Фоновый мост запускается автоматически при входе в macOS; держать терминал открытым не нужно.

1. Откройте бота и отправьте /start, чтобы увидеть кнопки.
2. Нажмите «🔴 Выключен · включить».
3. Нажмите «Выбрать чат» и выберите открытую беседу.
4. Отправьте задание обычным сообщением. Бот подтвердит добавление в очередь, затем запуск.
5. Дождитесь уведомления с последним ответом Codex.

По возвращении за компьютер нажмите «🟢 Включён · выключить». Мост продолжит принимать команды управления, но перестанет запускать новые задачи и пересылать ответы. Текущая работа Codex продолжится. Ответы, пропущенные при выключенном режиме, не пересылаются позже автоматически.

## Кнопки и команды

В первой строке одна кнопка режима: она показывает текущее состояние и действие при нажатии. После переключения подпись обновляется. Команды /on и /off также работают. Если видна старая панель, отправьте /start.


- /start — показать панель управления.
- /help или «Помощь» — краткий список команд и кнопка инструкции.
- /guide — эта подробная инструкция; доступна и при выключенном режиме.
- /on или «🔴 Выключен · включить» — разрешить уведомления и запуск задач из очереди.
- /off или «🟢 Включён · выключить» — отключить уведомления и приостановить запуск задач.
- /chats или «Выбрать чат» — десять последних обновлённых бесед, новые обращения выше.
- /use ID — выбрать беседу вручную по её техническому ID.
- /new или «Новый чат» — создать общий чат или выбрать рабочий проект.
- /status или «Статус» — режим, выбранный чат, активный запрос моста и размер очереди.
- /limits или «Лимиты» — остаток доступных окон Codex в процентах и время обновления по Москве.
- /queue или «Очередь» — список задач, пауза, продолжение, удаление задач.
- /stop или «Остановить запрос» — остановить запрос, запущенный мостом, и поставить очередь на паузу.
- /files или «Файлы» — выбрать файл из последнего ответа для скачивания.
- /approve ID и /decline ID — ответить на запрос разрешения; удобнее нажать его кнопку.

## В какой чат попадёт сообщение

Обычный промпт идёт в выбранную беседу. Чтобы продолжить другую беседу, нажмите «Ответить» на её уведомление в Telegram и отправьте новый промпт. Выбор чата отдельно не требуется: ответ на уведомление имеет приоритет.

В уведомлении указаны название беседы и строка «Чат: ID». Длинный ответ разбивается на части; можно отвечать на любую часть. Ответ на отправленный ботом файл также привязан к его беседе.

Чат фиксируется при добавлении промпта в очередь. Последующее переключение беседы не переместит уже добавленные задачи. Название помогает ориентироваться, но маршрутизация использует ID. Изменение названия не создаёт новый чат.

## Текст, диктовка, изображения и файлы

Для голосового ввода нажмите микрофон на клавиатуре телефона, произнесите задание и отправьте получившийся текст. Запись голосового кнопкой Telegram — другой формат: голосовые и аудиофайлы пока не расшифровываются.

Отправьте одно изображение или документ до 20 МБ. В подписи напишите задание, например «Найди ошибку на скриншоте» или «Кратко опиши документ». Без подписи агенту предлагается описать содержимое. Изображение передаётся как вложение; документ сохраняется на Mac, и Codex получает путь для чтения своими инструментами.

Альбомы, видео, видеосообщения, анимации и стикеры пока не поддерживаются. Вложения сохраняются в папке incoming проекта бота. Они не удаляются автоматически, чтобы ссылки в истории продолжали работать.

## Очередь задач

Все промпты попадают в общую очередь, максимум 20 задач. Мост запускает их по одной. Если первый чат занят работой в VS Code, закрыт или ждёт интерактивного ответа, очередь ждёт вместе с ним. Задачи других чатов не обходят первую.

В «Очереди» можно нажать «Пауза», «Продолжить», удалить отдельную задачу или очистить список. Удаление из очереди не отменяет уже запущенную задачу. Пауза тоже не останавливает текущую работу.

«Выключить» приостанавливает запуск. «Включить» возвращает его, если очередь не была отдельно поставлена на паузу. После «Остановить запрос» нажмите «Очередь» → «Продолжить», когда будете готовы запускать следующие задачи.

Очередь сохраняется при перезапуске моста. Статус pending означает ожидание; failed — ошибку подготовки; uncertain — отсутствие подтверждения запуска. failed и uncertain блокируют следующие задачи. При uncertain сначала проверьте историю VS Code: запрос мог уже запуститься. Затем удалите запись из очереди и, только если нужно, отправьте задание заново. Такие задачи не повторяются автоматически.

Не запускайте новые задания одновременно с телефона и компьютера в одной беседе.

## Новый чат

Нажмите «Новый чат». Появятся два варианта:

- «Общий чат» — для вопросов и задач без рабочего проекта. Каталог выбирать не нужно: бот подготовит отдельную техническую папку приложения.
- «Чат в проекте» — выберите папку из списка до десяти разных проектов недавних чатов. Общие чаты в этот список не входят. Новую папку с телефона пока задать нельзя.

Можно нажать «Отмена». Общий чат также выполняется на Mac и требует работающего VS Code; он не является облачной беседой без компьютера.

Новая беседа становится выбранной в боте и открывается в VS Code. Первый раз VS Code может спросить «Allow … extension to open this URI?». Нажмите Open. Чтобы следующие открытия работали без подтверждения на компьютере, отметьте «Do not ask again for this extension».

При создании модель не запускается. В историю добавляется короткая запись о создании через Telegram, чтобы сохранить беседу. История прежнего чата не переносится; настройки берутся из конфигурации Codex для папки. После открытия отправьте первый рабочий промпт.

Если бот пишет, что владелец недоступен, откройте эту беседу в панели Codex. Команда открытия сама по себе ещё не подтверждает, что VS Code принял чат.

## Разрешения

Когда Codex просит разрешить команду, изменение файлов или доступ к сети/папкам, бот показывает запрос с названием беседы и кнопками «Разрешить один раз» и «Отклонить». Прочитайте действие и выберите решение. Доступ выдаётся в объёме запроса на текущий ход, без постоянного разрешения.

Если запрос уже решён в VS Code, старая кнопка больше не действует. При сообщении об обновлении состояния повторите нажатие через несколько секунд. После перезапуска нерешённый запрос может появиться ещё раз.

При выключенном режиме решайте разрешения в VS Code либо включите бота. Другие формы, вопросы агента с вариантами ответа и вход OAuth пока требуют компьютера. Автоматически решённые настройками Codex запросы могут не требовать кнопки в Telegram.

## Скачать готовый файл

Нажмите «Файлы» для выбранной беседы или отправьте /files ответом на её уведомление. Бот покажет доступные локальные файлы, на которые агент дал Markdown-ссылки в последнем ответе этой беседы. Нажмите имя — файл придёт документом в Telegram.

Размер отправляемого файла — до 50 МБ. Он должен существовать внутри папки проекта беседы. Служебные файлы и ссылки за пределы этой папки не выдаются. Если список пуст, попросите: «Дай ссылку на готовый файл». Отправка происходит только по нажатию; вся папка автоматически не выгружается.

## Лимиты и состояние

«Лимиты» показывает данные аккаунта Codex, которым пользуется мост. Число оставшихся промптов не рассчитывается. Время обновления — московское. Нужен вход Codex через ChatGPT; аккаунт и CODEX_HOME должны совпадать с расширением.

«Статус» показывает активный запрос, запущенный мостом. Это не список всех текущих работ в VS Code.

## Если что-то не работает

- Бот молчит: проверьте интернет и сон Mac; затем состояние моста в терминале.
- Панель кнопок старая: отправьте /start.
- Очередь не движется: проверьте режим, отдельную паузу и первую задачу; откройте её чат в Codex.
- Ответ не пришёл: убедитесь, что режим был включён. Не повторяйте задание до проверки истории.
- uncertain: сначала проверьте, запускался ли промпт; затем удалите запись из очереди.
- Изображение не дошло: отправьте одно изображение, без альбома, до 20 МБ.
- Файлы не показаны: нужна ссылка в последнем ответе, существующий файл внутри папки проекта.
- Кнопка разрешения устарела: запрос мог быть решён за компьютером; дождитесь нового уведомления.

## Управление мостом на Mac

В терминале перейдите в папку проекта:

cd /Users/aleksejkalinicenko/Workspace/10_codex_remote_pult

python3 autostart.py status — состояние фонового процесса.
python3 autostart.py restart — применить обновление кода.
python3 autostart.py stop — остановить мост до следующего входа в macOS или команды start.
python3 autostart.py start — запустить установленный мост.
python3 autostart.py install — установить автозапуск на этом Mac.
python3 autostart.py uninstall — удалить автозапуск, сохранив файлы проекта.

Повторная настройка: python3 notify.py --setup. Токен вводится скрыто. Проверка доставки: python3 notify.py --test; она отправляет сообщение даже при выключенном режиме.

Логи находятся в logs/bridge.out.log, logs/bridge.err.log и server.log. Токен хранится в credentials.json. Не пересылайте этот файл и не публикуйте его.
