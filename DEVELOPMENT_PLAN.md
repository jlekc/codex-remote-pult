# План развития Кодекс Пульта

Актуально на 09.10.2026. Пульт работает локально на Mac с собственным аккаунтом Codex пользователя; общий сервер и многопользовательский relay отменены.

## Сделано

- Отдельные ветки Telegram с постоянной привязкой к беседам Codex.
- Создание общего чата или чата в проекте; выбор существующей беседы.
- Пересылка запросов с компьютера и только конечных ответов агента; телефонные запросы не дублируются.
- Нативная очередь Codex: атомарное добавление, просмотр и удаление ожидающих заданий. Локальный outbox переживает перезапуск; неопределённая передача не повторяется автоматически.
- Остановка выбранной беседы через исходного владельца VS Code; пауза передачи из Telegram.
- Вложения, получение готовых файлов, разрешения и формы вопросов, включая асинхронные вопросы длительных задач.
- Компактные сообщения, маркеры автора, постоянная клавиатура и удаление временных статусов.
- 20 последних бесед: сначала 5, затем кнопка «⬇️ Вывести следующие 5 ⬇️». Каждый следующий блок — отдельное сообщение; предыдущие списки сохраняются. Снимок списка фиксирован, повторы ID исключаются, выбор по неизменному ID. Меню сохраняется после перезапуска.

## Следующие проверки

1. ✅ Смешанная очередь: одновременно наблюдались КОМП2 из desktop и ТЕЛЕФОН2 из Telegram в одной тестовой беседе. Выполнились в порядке приёма, каждый ровно один раз; оба финала подтверждены квитанциями доставки в Telegram.
2. ✅ Перезапуск моста во время выполняющейся задачи и двух ожидающих запросов проверен. Очередь сохранилась, контрольные запросы выполнились без потерь и повторных выполнений.
3. ✅ Полный цикл асинхронного вопроса проверен в отдельной беседе: вопрос доставлен в Telegram, выбран ответ «АЛЬФА», агент продолжил исходную беседу и завершил ответом «ВЫБРАНО: АЛЬФА». Доставка финала подтверждена. Проверен механизм async-вопроса; длительная goal-задача отдельно не запускалась.
4. ✅ Пользователь подтвердил работу меню бесед и вывода следующего блока из 10. Выбор по ID, сохранение после перезапуска и старые кнопки покрыты автотестами. По последней просьбе пользователя размер блока уменьшен до 5; кнопка продолжения: «⬇️ Вывести следующие 5 ⬇️».

Тестовые задания отправлять только в отдельную беседу. Не очищать реальные очереди и историю ради проверки.

## Возможные улучшения — пока без отдельной задачи

- Поиск беседы по названию.
- Избранные беседы и более ясные названия одинаковых чатов.
- Запасная доставка в основной Telegram-чат, если создание ветки недоступно; явное уведомление о причине. Лимит количества частных веток Telegram официально не опубликован.
- Обработка удаления ветки пользователем и безопасное восстановление привязки без удаления истории Codex.

Эти улучшения не считаются заказанными или реализованными. Автоматически удалять ветки и переписку для освобождения места не планируется.


Меню чатов сохраняется вместе с кнопками: сообщения выбора не удаляются.
Вместо большого служебного заголовка используется короткая подпись
«💬 Чаты 1–5». Старые заголовки сокращаются через editMessageText
без изменения кнопок или привязок.
